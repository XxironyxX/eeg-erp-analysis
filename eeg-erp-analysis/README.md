# EEG ERP Analysis with MNE: P1 Peak Alignment

> 本科独立科研训练项目：基于 MNE 的 EEG ERP 分析，重点探索 **P1 峰值试次间对齐** 对 ERP 波形幅值的提升效果。

## 项目简介

本项目使用 MNE-Python 对公开 EEG 数据进行事件相关电位（ERP）分析，完成从原始数据到 ERP 成分提取的完整流程。

在经典 ERP 分析（滤波、分段、叠加平均）基础上，本项目额外实现了一个**逐试次 P1 峰值对齐算法**，用于减小单试次潜伏期变异对平均 ERP 的平滑效应，并量化对齐前后 P1 幅值的变化。

## 数据来源

- 数据：MNE 官方示例数据集 `sample_audvis_raw.fif`
- 内容：包含听觉与视觉刺激的 EEG/MEG 数据
- 说明：该公开数据无 oddball 范式，因此本项目分析 **P1 成分（约 70–150 ms）**，而非经典 P300

## 分析流程

1. **读取数据**：加载 MNE 示例数据，提取事件标记（STI 014）
2. **预处理**：
   - 保留 EEG 通道
   - 0.1–40 Hz 带通滤波
   - 50 Hz 陷波滤波
   - 平均参考
3. **分段（Epoching）**：
   - 时间窗：-0.2 至 0.5 s
   - 基线校正：(None, 0)
   - 伪迹拒绝：EEG > 150 μV
4. **P1 峰值对齐（核心算法）**：
   - 自动选择 P1 最强通道（枕区）
   - 逐试次在 70–150 ms 窗口内寻找经高斯平滑后的 P1 峰值
   - 计算每个试次相对平均潜伏期的偏移
   - 对刺激后数据进行平移对齐，基线区保持不动
5. **平均与量化**：
   - 分别计算原始 ERP 与对齐后 ERP
   - 提取 P1 潜伏期与幅值
   - 计算幅值提升百分比
6. **可视化**：
   - 对齐前后 P1 波形对比图
   - ERP 地形图
